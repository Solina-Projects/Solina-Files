# آمادگی انتشار — Solina Files (شاخهٔ `rewrite/solina-v2`)

> این سند فقط بر پایهٔ شواهد قابل‌بررسی نوشته شده است. هر چیزی که اجرا یا آزمایش نشده با «آزمایش‌نشده» مشخص است.

## ۱. نتیجهٔ کلی

**آمادهٔ انتشار عمومی نیست.** کد روی CI بیلد می‌شود و تست‌های واحد سبزند، اما رابط کاربری هرگز روی دستگاه یا Emulator اجرا نشده، و چند مورد مجوز هنوز باز است. انتشار عمومی تصمیم مالک پروژه است و بدون تأیید او انجام نمی‌شود.

برای انتشار آزمایشی (نسخهٔ پیش‌نمایش برای آزمایش‌کنندگان) پس از تست دستی روی دستگاه، وضعیت قابل‌قبول است.

## ۲. ساخت و نصب

نیازمندی‌ها: Android SDK و NDK، JDK 17، Rust با هدف‌های اندروید، `cargo-ndk`.

```bash
rustup target add aarch64-linux-android armv7-linux-androideabi x86_64-linux-android
cargo install cargo-ndk --locked
native/fetch-pdfium.sh
native/build.sh
./gradlew :app:assembleDebug
```

ساخت رسمی: workflow با نام Build در GitHub Actions (`.github/workflows/build.yml`). روی شاخهٔ `rewrite/solina-v2` به‌صورت خودکار راه نمی‌افتد (فقط `main` و `refactor/**`)؛ باید دستی با `workflow_dispatch` اجرا شود.

## ۳. قابلیت‌ها

حفظ‌شده: مرور فایل، دو پنل، عملیات فایل، آرشیو، ابزار APK/DEX، ذخیره‌سازی شبکه‌ای (WebDAV، FTP، SFTP، SMB)، اشتراک شبکهٔ محلی، Vault، مدیریت زبان‌ها، مدیر برنامه‌ها، انتخاب‌گر رنگ، کلیدهای امضا، افزونه‌ها.

افزودهٔ جدید: **مدیریت قابلیت‌ها** (تنظیمات ← قابلیت‌ها).
- هر قابلیت اختیاری یک کلید دارد؛ خاموش‌کردن فقط ورودی‌ها را از منو پنهان می‌کند و هیچ داده‌ای حذف نمی‌شود.
- قابلیت‌های ضروری (مرور فایل، تنظیمات) قابل خاموش‌شدن نیستند.
- وابستگی‌ها رعایت می‌شوند: «اشتراک شبکهٔ محلی» بدون «ذخیره‌سازی شبکه‌ای» فعال نمی‌شود.
- انتخاب‌ها در DataStore ذخیره می‌شوند و در پشتیبان‌گیری تنظیمات هم قرار می‌گیرند.

## ۵. تغییرات ساختاری

نسبت به `main`: ۴۶ فایل، ‎+2314 / −911 خط. `ExplorerScreen.kt` از ۱۱۲۷ به حدود ۴۹۶ خط رسید و کلاس‌های `BookmarkEditor`، `ExplorerRules`، `SigningKeyResolver`، `RemoteEditTracker` و چند فایل رابط جدا شدند. `ExplorerViewModel.kt` هنوز حدود ۱۳۴۰ خط است.

## ۶. امنیت و حریم خصوصی

- ترافیک clear-text عمداً مجاز مانده است، چون WebDAV روی `http://` و ابزار HTTP با آدرس واردشدهٔ کاربر کار می‌کنند و Network Security Config نمی‌تواند بازهٔ IP شبکهٔ محلی را مجاز کند. دلیل در خود فایل مستند است. پیشنهاد: هشدار در رابط هنگام اتصال WebDAV بدون TLS (انجام نشده).
- مورد زیر بازبینی نشده: `TlsInspector` (TrustManager پذیرندهٔ همه)؛ محتوای کامل آن خوانده نشده.
- تغییری در ارسال داده به سرویس خارجی ایجاد نشده است.

## ۷. موارد باز

1. **مجوزها (تصمیم/بازبینی مالک):** مجوز `dcerpc` (سفارشی) و `desugar_jdk_libs` (ترکیبی) بازبینی نشده؛ Cargo.toml بومی Apache-2.0 می‌گوید ولی پروژه AGPL است؛ توزیع Sora Editor (LGPL-2.1+) نیاز به بررسی دارد. تغییر مجوز بدون تأیید مالک انجام نمی‌شود.
2. **تست روی دستگاه:** رابط، دسترس‌پذیری، تبلت/تاشو، صفحهٔ «قابلیت‌ها».
3. **ترجمه:** رشته‌های جدید برای روسی و چینی ندارند و به انگلیسی برمی‌گردند.
4. **ادامهٔ شکستن ViewModel** (ناوبری، عملیات فایل، ابزار APK/DEX، Vault) و بدنهٔ `ExplorerScreen`؛ به‌دلیل وضعیت مشترک پرخطر است و با CI پس از هر برش بررسی شود.
5. **وابستگی به Material3 Expressive نسخهٔ alpha.**
6. **CI:** افزودن `rewrite/**` به trigger یا ادغام شاخه.
